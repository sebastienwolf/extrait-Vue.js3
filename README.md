Ce repository présente quelques exemples représentatifs de mon travail avec Vue.js 3 et TypeScript.

L’objectif n’est pas de reproduire l’intégralité d’un projet professionnel, mais de montrer différentes pratiques que j’utilise au quotidien : architecture de composants, gestion d’état avec Pinia, appels API avec Axios, routing, logique métier, gestion asynchrone, tests avec Vitest et quelques exemples d’optimisation frontend.

Les exemples ont été adaptés afin de pouvoir être partagés publiquement, tout en respectant la confidentialité du code et des données des projets professionnels sur lesquels j’ai travaillé.
